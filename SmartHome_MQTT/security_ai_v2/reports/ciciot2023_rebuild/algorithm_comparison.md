# So sánh thuật toán

IMPLEMENTED và VERIFIED_OFFLINE trên fixture của sáu thuật toán Logistic Regression, Random Forest, Extra Trees, XGBoost, LightGBM và HistGradientBoostingClassifier. Mỗi thuật toán có preset quick/default/strong, giới hạn tham số hợp lệ và cấu hình run riêng. Batch chạy tuần tự; lựa chọn dựa trên attack recall, FPR và F1 trên validation.

Không có run chạy trên CIC thật. Registry thực tế trống. Chưa có so sánh accuracy, recall, FPR, AUC, latency hay kích thước model giữa các thuật toán trên dữ liệu thật.
